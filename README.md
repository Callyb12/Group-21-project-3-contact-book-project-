# Contact Book
**Live Demo:** https://callyb12.github.io/Group-21-project-3-contact-book-project-/

## Project Description

A simple contact management application that allows users to store, view, search, edit, and delete personal contacts.

## Project Requirements

The Contact Book application will:

1. Allow users to add a new contact with:

   - Full Name

   - Phone Number

   - Email Address

2. Display all saved contacts.

3. Allow users to edit contact information.

4. Allow users to delete contacts.

5. Allow users to search for contacts by name.

6. Save contacts using browser Local Storage.

7. Validate phone number and email fields.

8. Provide a clear and organized display of contact details.

## Technologies Used

- HTML

- CSS

- JavaScript

- Local Storage

- Git

- GitHub

## Planned JavaScript Structure

- Contact class for representing contact information

- Functions for adding, displaying, editing, deleting, and searching contacts

- Local Storage functions for saving and loading contacts

- Validation functions for phone numbers and email addresses

## Expected Input

The user enters:

- Full Name

- Phone Number

- Email Address

## Expected Output

The application displays each contact in an organized contact card with options to:

- Edit

- Delete

The application also provides a search field for finding contacts by name.
